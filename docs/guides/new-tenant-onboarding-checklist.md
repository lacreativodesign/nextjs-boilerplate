# New Tenant Onboarding Checklist

Use this checklist when launching a new Bizosto workspace.

1. Confirm company profile is completed (name, logo, timezone, currency)
2. Verify required modules are enabled for the tenant
3. Verify required roles are enabled for the tenant
4. Invite core team users and confirm sign-ins
5. Add first client and validate client profile fields
6. Create first invoice and confirm invoice delivery
7. Connect Stripe account in `/settings/payments`
8. Confirm payment method and subscription status in `/billing`
9. Configure tax rates in `/finance/tax` (if applicable)
10. Set performance targets for operational roles
11. Run core workflow validation (lead → invoice → payment)
12. Review audit logs and monitoring for setup issues
