# Finance User Guide

## Invoices
- Create invoice: **Finance → Invoices → New Invoice**
- Add line items, tax rate, and due date
- Send invoice by email or share payment link
- Client payment path: `/pay/[invoiceId]`

## Tax Management
- Configure rates at **Finance → Tax**
- Set default tax for automatic invoice application
- Generate quarterly and annual tax reports

## Reports
- Revenue reports
- Expense reports
- Profit and loss overview
- Export CSV for accounting workflows
