# Sales Manager Guide

## Team Overview

- Dashboard shows team pipeline, total leads, and revenue
- Performance page shows each sales user’s target progress

## Setting Team Targets

- Go to `/sales_manager/performance`
- Click **Set Targets** for a team member
- Define monthly/quarterly/annual targets for:
  - Leads Created
  - Deals Closed
  - Revenue Generated
- Updates are applied immediately to the sales user performance page

## Pipeline Management

- Access full team pipeline from the Sales Manager dashboard
- Filter by stage, assigned user, or date range
- Use **Reports → Sales** for detailed pipeline analytics
